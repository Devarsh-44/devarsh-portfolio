RCintel Brand Kit  v2.0  (October 2026)
=======================================

01-Signature-Lockup   PRIMARY LOGO. RC monogram + shift lights, "intel" in Sacramento across its base.
                      foil-for-dark / almond-for-dark ... on Night Slate
                      slate-for-light ................... on Off-White or Almond
                      mono-slate / mono-almond / mono-white  one-colour (print, embroidery, stamps)
                      Minimum width 100 px / 28 mm. Below that, use the Monogram.

02-Badge              Profile icon: character in the blue-gray circle.
                      badge (full detail, 64 px and up), badge-flat (small sizes),
                      512 / 180 px (profile photo, apple-touch-icon), 64 / 32 / 16 px (favicons)

03-Horizontal-Lockup  Badge + Signature for headers and wide, short spaces.

04-Monogram           RC + shift lights, no script. Watermarks (one-colour versions at 40-60% opacity), merch.

05-Stack-and-Seal     Studio Stack (Signature over DESIGN STUDIO) and the Studio Seal.

06-Colours            rcintel-colours.txt (HEX / RGB / CMYK / usage + foil gradient)
                      rcintel-tokens.css (CSS variables for the website)

07-Fonts              Sora, Inter, Sacramento: all free, SIL Open Font Licence.

Colour check: every file in this kit uses only the palette values listed in 06-Colours
(plus white highlights and the foil gradient stops). The gap behind "intel" is a true cut-out,
so the logos work on any background.

RCintel-Brand-Guidelines.html  The full guidelines. Open in any browser.

Note: the monogram's R and C are traced from a reference alphabet you supplied.
